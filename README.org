* 简介

Emacs 30.1+ 个人配置，macOS（Apple Silicon）专用。

- 包管理：Borg + git submodule
- 编辑模型：Evil (Vim 按键)
- 补全系统：Corfu + Vertico + Consult + Orderless
- 知识管理：Org-mode + Org Roam + Org Journal

* 快速开始

#+begin_src bash
git clone <repo-url> ~/.emacs.d
cd ~/.emacs.d
make bootstrap-borg
make bootstrap
#+end_src

首次启动后按需运行 =M-x rime-compile-module= 编译 Rime 动态模块。

* 性能

| 场景 | 耗时 |
|------|------|
| 批处理加载 (--batch) | ~0.98s |
| 命令行 GUI 启动 | ~1.0s |
| Dock 图标启动 | ~2.0s |

Dock 启动多出的时间主要来自 macOS App 进程拉起 + GUI frame 创建，非配置问题。
