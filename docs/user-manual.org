#+subtitle: Emacs 配置使用指南（重点：快捷键速查）

* 编辑模型：Evil (Vim 按键)

本配置默认开启 Evil 模式，使用 Vim 风格的 Normal/Insert/Visual 状态。

| 状态   | 光标颜色     | 模式行标识 | 用途                 |
|--------|------------|----------|----------------------|
| Normal | 暗金色 box  | =[N]=    | 导航、命令、操作       |
| Insert | 亮绿色 bar  | =[I]=    | 文本输入              |
| Visual | 红色 hbar   | =[V]=    | 文本选区              |
| Emacs  | 天蓝色 box  | =[E]=    | 兼容 Emacs 原生快捷键 |

Emacs 状态 (=C-z= 进入) 下保留原生 C-x/C-c 等按键，方便逐步适应。

* 补全系统

使用 Corfu + Vertico + Consult + Orderless 组合：

- 输入时自动弹出 Corfu 补全菜单
- =TAB= 选择候选项
- =M-x= 使用 Vertico 增强的完成
- =C-s= 触发 consult-line 搜索
- 支持拼音首字母搜索（orderless + pinyinlib）
